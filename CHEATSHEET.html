Claude Mods cheat sheet

Nine mods, installed from ~/Documents/Claude/claude-mods. Type /mods to see and switch them.

9 mods never block a prompt switch any off

Daily routine

1StartDictate 40+ words. brain-dump tidies it. Read, edit, Enter.
2WorkWatch the purple bar. /helpers for subagents.
3Review/replay steps through the edits before you accept.
4Correctreflect may offer a rule. Edit it short, then save.
5Long chat/handoff starts a fresh chat. Watch the clock.

The nine mods

Bbrain-dumpPrompt

Turns a rambling dictation into a clear prompt. Asks 1 to 3 multiple-choice questions only for real gaps.

  • End a message with !! to send it exactly as typed
  • /braindump undo puts your original back in the box
  • /braindump delivery review|confirm|auto
  • /braindump format standard|four-part, on, off, status

Hhelper-desk/helpers

Purple task bar above the prompt that fills as Claude ticks off its to-do list. A pane with one live card per subagent.

  • Press ✕ on the bar to dismiss it. It returns on the next list
  • /helpers hide and /helpers clear
  • Settings: bar colour, animations, pop-ups, reminders

Rreplay-theater/replay

Steps through Claude's file edits one diff at a time. Good for theme and Liquid changes.

  • r open, n next, p previous, c close
  • /replay list and /replay 2 for earlier turns
  • Copy or save a patch for a step, file or turn

Hhandoff/handoff

Writes a handoff of a long chat and starts a fresh one. Saves a draft first, so nothing is lost.

  • Offers itself at 250k tokens (a setting). Snooze adds 100k
  • /handoff <focus> to steer it, /handoff last to reopen
  • Secrets are redacted. Files are saved privately

Ccache-clockAbove prompt

Counts down until the chat's prompt cache goes cold. Offers /handoff when a big chat does.

  • Keep warm costs tokens: opt-in, capped, priced. Leave it off
  • /cacheclock status, hide, /keepwarm status|off
  • A "guess" label means the cache length is estimated

Rreflect/reflect

When you correct Claude, offers to save the fix as a lasting rule. Shows the exact text first. Every write can be undone.

  • Scopes: everywhere (CLAUDE.md), this project, or a rules folder
  • /reflect undo, list, mute, status
  • Your backup is CLAUDE.md.backup

Ichat-inventory/inventory

A pane of what this chat used: to-do list, connectors with call counts (Shopify, Figma, Slack), files and skills.

  • Press a connector to see its calls
  • /inventory copy copies the list as text
  • /inventory hide closes the pane

Sscreen-share/screen-share

Hides names, emails, phones, amounts and secrets on screen while you record. Claude still reads the real data.

  • /screen-share on|off|status. Check the "ON" badge first
  • /screen-share peek 20 reveals for 20 seconds
  • Cannot hide: window title, sidebar, images, the box while typing

Mmods/mods

The switchboard. Turn each mod on or off in every chat, and open the ones that have panes.

  • /mods list, /mods off helper-desk
  • Press Off twice on mods itself, on purpose
  • "Turn Mods back on" if you switch it off

Noisy or wrong?

  • Switch it off in /mods, or put {"brain-dump": false} in ~/.claude/claude-mods/switches.json
  • Mods never block your prompts. If one breaks, the original goes through
  • Logs, no prompt text: ~/.claude/claude-mods/logs/
  • Settings: /plugin configure <mod>@claude-mods

Edit a mod, then reload

  • Mods load straight from the folder. Edit, then /reload-plugins or start a new chat
  • Commit in the folder before big changes
  • Keep Claude Code current: claude update (2.1.309 or newer)

Good to know

  • Hooks skipped? A built-in security plugin can override some events. The effect is small
  • brain-dump and cache-clock make extra small model calls through your own session
  • One README per mod in the folder
